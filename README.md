# Yemek Sitesi (HTML & CSS)

Bu proje, temel HTML ve CSS bilgilerini pekiştirmek amacıyla geliştirilmiş statik ve responsive bir yemek vitrini uygulamasıdır. Herhangi bir JavaScript kütüphanesi veya framework kullanılmadan yalnızca saf HTML5 ve CSS3 ile hazırlanmıştır.

## Özellikler

- **Bölümlendirilmiş Menü Yapısı:** İndirimli yemekler, popüler yemekler ve tüm yemekler bölümleri.
- **Arama ve Gezinme Alanı:** Üst gezinme menüsü, arama kutusu ve hero alanı.
- **Etkileşimli Hover Efektleri:** Butonlarda renk değişimi ve yemek kartlarında ölçeklenerek büyüme (`transform: scale()`) efekti.
- **Responsive Tasarım:** Flexbox yapısı ve medya sorguları (`@media`) ile farklı ekran boyutlarına uyum.

## Kullanılan Teknolojiler

- HTML5
- CSS3 (Flexbox, Media Queries, Transitions & Transforms, OKLab / HSL / HWB renk tanımları)
